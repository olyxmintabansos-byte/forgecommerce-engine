## 🎯 Mengapa ForgeCommerce?
Sebagian besar template e-commerce gratis di internet memiliki desain usang, lambat, dan penuh kode boilerplate yang tidak efisien.

**ForgeCommerce** hadir dengan pendekatan **Headless & Local-First SPA**:
* ⚡ **Super Cepat & Ringan:** First Load JS sangat ramping (~11 kB) berkat Next.js 15 App Router & Tailwind CSS v4.
* 🛒 **Quick-Cart Drawer:** Keranjang belanja geser samping yang mulus tanpa reload halaman, lengkap dengan input voucher diskon otomatis.
* ⏱️ **Hero Flash Sale:** Banner promosi interaktif dengan hitung mundur waktu nyata (*real-time countdown timer*).
* 🔍 **Filter & Sorting Dinamis:** Filter berdasarkan kategori produk, pencarian real-time, dan pengurutan harga termurah/terlaris.
* 🚚 **Kalkulator Ongkir Nusantara (Sprint 2):** Simulasi tarif pengiriman JNE, J&T, SiCepat antarkota Indonesia.
* 💳 **Payment Gateway Simulator (Sprint 2):** Mockup checkout Virtual Account & QRIS dinamis ala Midtrans/Xendit.

## 🚀 Menjalankan Secara Lokal

```bash
# Clone repository
git clone https://github.com/olyxmintabansos-byte/forgecommerce-engine.git
cd forgecommerce-engine

# Install dependensi
npm install

# Jalankan development server
npm run dev

# Kompilasi build statis untuk GitHub Pages
npm run build
```
